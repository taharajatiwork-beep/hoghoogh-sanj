# حقوق‌سنج

سایت مرحله‌به‌مرحله‌ی «حقوقت چقدر می‌ارزه؟» با نرخ زنده‌ی دلار و سکه، به‌علاوه‌ی بک‌اند برای نگه‌داشتن مخاطب.

## اجرا
```bash
npm install
cp .env.example .env     # مقدارها را پر کن (همه اختیاری‌اند)
npm start                # http://localhost:8765
npm test                 # ۱۶ آزمون، بدون نیاز به اینترنت
```
نیاز: Node 22.5 یا بالاتر (SQLite داخلی). فقط دو وابستگی دارد (`@napi-rs/canvas` و فونت `vazirmatn`) برای ساخت تصویر پیش‌نمایش لینک.

## بک‌اند چه می‌کند
| بخش | کار |
|---|---|
| `/api/rates`، `/api/history/*` | نرخ‌ها را از آرشیو bonbast و CoinGecko می‌گیرد، ۳۰ دقیقه کش می‌کند، و اگر منبع قطع شد آخرین نرخ را می‌دهد |
| `/api/submit` | حقوق را **ناشناس** (با شناسه‌ی تصادفی مرورگر، نه IP) ذخیره می‌کند و درصد «از چند درصد کاربرها بیشتری» را برمی‌گرداند. زیر ۳۰ نفر درصدی نشان داده نمی‌شود |
| `/api/challenge`، `/c/<id>` | لینک چالش دوستان؛ فقط مبلغ دلاری ذخیره می‌شود، نه حقوق تومانی |
| `/og/c/<id>.png` | تصویر پیش‌نمایش لینک برای ایکس و تلگرام، با عدد همان چالش |
| `/api/event` | شمارنده‌ی ناشناس هر مرحله (قیف ریزش) |
| `/api/admin/stats?token=…` | آمار مدیریتی (فقط با `ADMIN_TOKEN`) |
| ربات تلگرام | گزارش هفتگی شخصی و پست هفتگی کانال |
| `lib/xpost.js` | پست هفتگی در ایکس |

## چیزهایی که خودت باید تنظیم کنی (در `.env`)
- `BASE_URL`: آدرس عمومی سایت. بدون آن لینک‌های اشتراک و پیش‌نمایش‌ها به localhost اشاره می‌کنند.
- `X_HANDLE`، `TG_BOT`، `TG_CHANNEL`: خالی باشند، دکمه‌شان در سایت نمایش داده نمی‌شود.
- `TELEGRAM_BOT_TOKEN` (از @BotFather) و `TELEGRAM_CHANNEL_ID`: ربات باید ادمین کانال باشد.
- `X_API_KEY`، `X_API_SECRET`، `X_ACCESS_TOKEN`، `X_ACCESS_SECRET`: از developer.x.com، با دسترسی نوشتن.
- `ADMIN_TOKEN`: یک رشته‌ی طولانی تصادفی.

## پست هفتگی در ایکس
```bash
node lib/xpost.js          # فقط پیش‌نمایش متن
node lib/xpost.js --send   # ارسال (نیاز به کلیدها)
```
هفته‌ای یک بار با cron یا Task Scheduler اجرا کن. ربات تلگرام خودش هفتگی ارسال می‌کند.

## استقرار
یک سرور کوچک (VPS یا Railway/Fly/Render) کافی است. دایرکتوری `data/` باید روی دیسک پایدار باشد (دیتابیس آنجاست). پشت nginx/Cloudflare `TRUST_PROXY=1` بگذار و HTTPS را آنجا فعال کن.
